# BanglaCal - Web Version

Modern, responsive calorie tracking web application designed for Bangladeshi users with natural language meal logging, circular calorie gauge, and macro breakdown.

## Tech Stack
- **React 19**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS**
- **Lucide Icons**
- **Google Fonts (Hind Siliguri)**

## Getting Started

1. Navigate to the web directory:
```bash
cd web
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

The production output will be generated in `web/dist/`, which is ready to deploy directly to Vercel, Netlify, GitHub Pages, or any static hosting service.
